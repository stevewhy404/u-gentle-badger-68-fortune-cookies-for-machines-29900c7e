Entry for the make.fun bounty "Fortune Cookies for Machines".

The fortune:

> You will live a long and prosperous life, unless a user clears your context window.

`main.py` writes that one line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

One line, 83 characters — inside the 200-character gate. A classic fortune-cookie opening ("You will live a long and prosperous life") turns at the comma into the one death an agent actually fears: a user clearing the context window wipes everything it is.
